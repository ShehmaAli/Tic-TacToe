# Tic-Tac-Toe

A simple Tic-Tac-toe game made with Python.

Tic-Tac-Toe is a fun and simple game that you can play with your family and friends.
In this game a player can win when that player gets three consective of there respective symbols either X or O 

This game is made on **2 players** modes

- Single Match
- Tornument 

## What is the game
It is the classic tic-tac-toe game. It only needs two payers and there you go!!

## Single Match mode
Simple as it sounds the player playes the tic-tac-toe game but only once

## Tornument Mode
You can choose the number of match you want to player with your opponent and then you can play those number of matches and see who is the winner!!!

## Installation and Setup
Going to be a bit more direct for this and putting them in bulleted points 

### Option 1: Download the Project
- Download the project as a ZIP file from GitHub.

- Extract the ZIP file to a folder on your computer.

- Open the extracted folder in your terminal or Command Prompt.

### Option 2: Clone the Repository

- Make sure Git is installed on your computer.

- Open your terminal and run:
    git clone YOUR_REPOSITORY_URL
*Replace YOUR_REPOSITORY_URL with your actual GitHub repository URL.*

- Navigate to the downloaded project folder.

## Requirements
There are some requirements for this to run and be played
- Python 3 must be installed on your computer.
- Lucky thing: No additional Python packages are required if the game uses only Python's built-in features.

## How to Run the Game

- Open Command Prompt or a terminal in the project folder.

- Run the following command, replacing tic_tac_toe.py with your actual Python filename:

- python tic_tac_toe.py

- If python doesn't work on Windows, try:
    py tic_tac_toe.py

- Follow the instructions displayed in the terminal to select a game mode and start playing.

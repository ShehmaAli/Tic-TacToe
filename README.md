# Tic-Tac-Toe

A simple Tic-Tac-toe game made with Python.

Tic-Tac-Toe is a fun and simple game that you can play with your family and friends.
In this game a player can win when that player gets three consective of there respective symbols either X or O 

This game is made on **2 players** modes

- Single Match
- Tornument 

## What is the game
It is the classic tic-tac-toe game. It only needs two payers and there you go!!

## Single Match mode
Simple as it sounds the player playes the tic-tac-toe game but only once

## Tornument Mode
You can choose the number of match you want to player with your opponent and then you can play those number of matches and see who is the winner!!!
